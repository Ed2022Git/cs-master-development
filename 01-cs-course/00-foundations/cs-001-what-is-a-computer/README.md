\# CS-001 — What Is a Computer?



\## Status



Not started



\## Learning Objectives



By the end of this module I should be able to explain:



\- what a computer is

\- the difference between hardware and software

\- CPU

\- RAM

\- storage

\- input and output

\- what a program is

\- what an instruction is

\- what an operating system does

\- the basic path from source code to execution



\## Mastery Criteria



To complete this module I must demonstrate:



\### Explain

Explain the major components of a computer without notes.



\### Implement

Complete the practical exercises assigned in the module.



\### Debug

Identify incorrect statements or diagrams about computer execution.



\### Transfer

Apply the concepts to an unfamiliar computer or computing scenario.
